/etc/hosts file contains information using which it determines dns mapping [hostname to ip]. This concept is called host resolution.
But if we manage everything at local system, then for every other computer we have to do the same thing. In order to get rid of it, we use a central server
called dns server, and in that server do the host resolution.
then, we point every local system to get information from that dns server. to point,we update the /etc/resolv.conf file and add the dns server

nameserver 8.8.8.8


order is 
- /etc/hosts
- local dns server
- 8.8.8.8 [google public dns]

- nslookup google.com [only quries dns server not the /etc/hosts]
