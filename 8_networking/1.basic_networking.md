Network - internet of internets [Computers connected with other computers]

To connect one computer with other, we have the following options
- Connect directly via wire, when multiple computers will be connected to each other, each computer need to know each other
- We can introduce a central device, which has information about all the computers, We call this central device a switch

An interface/port [physical or virtual] is needed in order to connect a computer with switch.  
To check all the interfaces, we use the following command
`ip link`

there could be wireless interfaces,  ethernet interfaces

Basically, IP addresses are assigned to these interfaces. To manually assign an ip address to an interface,  we can do
`ip addr add <IP_ADDRESS>/<subnetMask> dev <INTERFACE_NAME>` [dev stands for device]

Switch for internal communication only.


To send traffic outside, we need a device for which our network is local as well and some other network, which should. be local for it 
too.  That deivice is called router. It has two interface, one has ip addresses from our network and other from different network.

C1 [A1] - [A2] [ROUTER] [B2] - C2 [C1 and C2, both on different networks]


`ip route`
`ip route add 192.68.1.0/24 via 192.168.2.1`
`cat /proc/sys/net/ipv4/ip_forward`

- Adding routes towards router
- enable traffic forwarding from one interface to other
