Services: They are a k8s object and A way to communicate with Pods.
Types:
- If you want the pods to communicate privately, service type will be ClusterIP, used for internal Communicatin
- If we want to expose the pod, so user can access whatever is ruuning inside, use NodePort [not a good way to expose], then, use the node ip and port number 
- type: LoadBalancer, this will provison a load balancer in the cloud, through which you can expose your services.
